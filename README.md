# CBR ASSISTENTE BÍBLICO

Um chatbot teológico especialista na Bíblia Sagrada, desenvolvido sob a perspectiva Batista da Restauração e Carismática. Este aplicativo permite aos usuários explorar as escrituras, tirar dúvidas teológicas, ler a Bíblia e estudar eventos bíblicos em ordem cronológica.

Construído como um Progressive Web App (PWA), ele pode ser "instalado" em qualquer dispositivo (celular, tablet ou computador) e funciona até mesmo offline.

## ✨ Funcionalidades

- **Chat com IA Teológica:** Converse com um assistente treinado para responder perguntas com base nas Escrituras, sob uma perspectiva Batista da Restauração e Carismática.
- **Leitura da Bíblia Completa:** Navegue e leia qualquer capítulo do Antigo e Novo Testamento diretamente no aplicativo.
- **Estudo Cronológico:** Explore os principais eventos da história bíblica, desde a Criação até a Igreja Primitiva, em uma linha do tempo interativa.
- **Instalável (PWA):** Adicione o aplicativo à sua tela inicial e use-o como um aplicativo nativo.
- **Funcionalidade Offline:** Após a primeira visita, o aplicativo funciona mesmo sem conexão com a internet.
- **Seguro:** Sua Chave de API é armazenada apenas no seu navegador, nunca no código público.

## 🚀 Como Usar e Publicar

Este projeto foi projetado para ser publicado gratuitamente no GitHub Pages. Siga estes passos para ter sua própria versão do assistente online.

### Pré-requisitos

Você precisará de uma **Chave de API do Google Gemini**. Ela é gratuita e fácil de obter.

1.  Acesse o **[Google AI Studio](https://aistudio.google.com/app/apikey)**.
2.  Faça login com sua conta do Google.
3.  Clique em **"Create API key"** para gerar sua chave.
4.  **Copie e guarde** essa chave em um local seguro.

### Passos para Publicação no GitHub

1.  **Crie um Repositório no GitHub:**
    *   Vá para o [GitHub](https://github.com) e crie um novo repositório. Dê a ele o nome que preferir (ex: `assistente-biblico`).

2.  **Envie os Arquivos do Projeto:**
    *   Envie todos os arquivos deste projeto para o seu novo repositório no GitHub.

3.  **Ative o GitHub Pages:**
    *   No seu repositório, vá para **Settings** > **Pages**.
    *   Na seção "Build and deployment", em "Source", selecione **Deploy from a branch**.
    *   Em "Branch", selecione a branch `main` (ou `master`) e a pasta `/(root)`.
    *   Clique em **Save**.

4.  **Aguarde a Publicação:**
    *   O GitHub levará alguns minutos para publicar seu site. O link do seu aplicativo aparecerá no topo da seção do GitHub Pages (ex: `https://SEU-USUARIO.github.io/assistente-biblico/`).

5.  **Use o Aplicativo:**
    *   Acesse o link gerado.
    *   Na primeira vez que abrir, o aplicativo pedirá sua Chave de API do Gemini.
    *   **Cole a chave** que você obteve no pré-requisito e comece a usar!

Agora você pode compartilhar o link do seu aplicativo com qualquer pessoa!
